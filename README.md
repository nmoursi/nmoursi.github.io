# nmoursi.github.io

Personal academic site for Nada Moursi, served by GitHub Pages at https://nmoursi.github.io

## Files

    index.html                    all page content
    style.css                     all styling (light + dark mode, responsive)
    images/nada.jpg               headshot (optional — falls back to an "NM" monogram)
    files/Nada_Moursi_CV.pdf      academic CV
    files/Nada_Moursi_Resume.pdf  industry resume

## Publishing

1. Upload every file and folder here to the repository (Add file -> Upload files, then drag them in).
2. Settings -> Pages -> Build and deployment -> Source: "Deploy from a branch",
   Branch: `main`, Folder: `/ (root)` -> Save.
3. Wait about a minute, then open https://nmoursi.github.io

## Editing later

All text lives in `index.html` between the `<section>` tags — edit it directly on GitHub
(open the file, click the pencil icon, commit). The site rebuilds automatically.

To swap the CV, replace the PDF in `files/` keeping the same filename.
